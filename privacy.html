Collab-Sorter — Privacy Policy

Last updated 3 September 2026

Collab-Sorter is a private tool used by one person to triage collaboration offers in their own email inbox. It is not a product, it is not offered to the public, and it has no users other than its owner.

What it accesses

With the account holder's explicit Google consent, Collab-Sorter reads email using the gmail.readonly scope. That scope is read-only: the application cannot send, delete, or modify mail, and it does not request any scope that would allow it to.

Where the data goes

Email is fetched to a single personal computer and stored only on that machine. There is no server, no hosting provider, no database, and no account system. Nothing is uploaded to a website.

One third party is involved. To decide whether a message is a genuine collaboration offer or a scam, the text of candidate messages is sent to Anthropic's API for classification. Anthropic processes it to return that answer. No other third party receives message content, and the data is not sold, shared, or used for advertising by anyone.

What is kept, and for how long

The tool stores what it needs to rank offers: sender, subject, extracted figures, and its own verdicts. Message bodies are not retained after classification. Access tokens are encrypted at rest on the local machine.

Revoking access

The account holder can revoke Collab-Sorter's access at any time at myaccount.google.com/permissions. Revoking stops all access immediately.

Contact

Questions about this policy, or a request about data: open an issue on GitHub. That is a public tracker, so please do not include anything private in it.
