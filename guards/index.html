Scans that reported clean because they couldn’t run

A tool that finds and removes dangerous credentials, reporting nothing to remove — because it was never allowed to look.

An empty result and a refusal look identical

Ask an API for a list of things you are not permitted to see, and it does not hand you an error you can trip over. It hands you a shrug. One layer downstream, that shrug has become an empty list, and an empty list means good news.

So the report said zero. It said zero three separate times, to people who had every reason to believe it, about a class of credential that very much existed. Nothing was broken in any way a passing run would reveal — the scan was working perfectly, on nothing at all.

The first rule: refuse to be reassuring

A check that cannot run must never render as a clean result. Permission failures now stop the run and say so by name, rather than flowing downstream to be counted as an absence of findings. “I couldn’t look” and “I looked and there was nothing” are different sentences, and only one of them is evidence.

The guards went in before the destructive half of the tool was allowed to run at all. On their first execution they caught nine violations in scripts that had been considered finished.

Then: test the tests, by breaking the code

A green suite proves the tests ran. It does not prove they would have noticed anything. The only honest way to find out is to damage the code deliberately and check that the suite screams.

Eight sabotages went in, one at a time, each a plausible mistake a tired person would make. The suite caught eight of eight. Getting there took the assertions from around twenty-two to forty-one — and most of those additions exist because a sabotage walked straight past the originals.

What it is now

The repository gained its first continuous integration in the same change: automated guards, plus a runner that executes the whole fixture suite on every push. The tooling is still capable of deleting things. It is now considerably harder for it to delete the wrong things quietly, or to tell you it found nothing when it was never permitted to look.

Client, vendors and internal systems are unnamed on purpose — the method is mine to describe, the specifics aren’t.
