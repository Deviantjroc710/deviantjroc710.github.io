“Console-only,” allegedly

A security review that existed only as somebody clicking through an admin console, turned into something anyone can run again next quarter.

A review you can’t re-run is an anecdote

Someone opens a console, reads some screens, and writes down what they saw. Six months later the only artifact is that document, and there is no way to tell whether it is still true without repeating the whole ritual — assuming you still remember which screens, in which order, and what counted as correct.

Worse, nobody can check the reviewer’s work. A conclusion arrived at by looking is a conclusion nobody else can reproduce, which puts it somewhere between a measurement and a memory.

I was told three times it couldn’t be scripted

It could. Most of it, anyway — which is the usual shape of that answer. “Console-only” almost always means nobody has needed it badly enough to find the interface, not that no interface exists.

The part that genuinely was manual turned out to be small, and once it was isolated it could be written down precisely instead of hiding inside a much larger claim. That is a better outcome than either answer on its own: most of the review became repeatable, and the remainder became explicit.

Control cases, or it proves nothing

A sweep that reports “no problems” is worthless until you have watched it report a problem. So the checks run against known-good and known-bad inputs on every execution. If the case that is supposed to fail comes back clean, the sweep has broken and says so, rather than handing over a reassuring page of green.

The part most tools leave out

The re-check tool prints what it could not verify. Not as a footnote — as a section, alongside the results, listing every question it was unable to answer and why.

Coverage is the thing reviews quietly lie about. A tool that checks eleven of fifteen things and reports on eleven has told you the truth about each one and a lie about the whole. Naming the four is the difference between a report and a reassurance.

And a baseline with a date on it

Every run is stamped and kept, so the next one is a comparison rather than a fresh opinion. Drift becomes visible on its own, without anyone having to remember what last quarter looked like.

The findings themselves stay private — some describe things that are still being fixed. The method is what’s mine to write about.
